Dados do cursinho

Backup e armazenamento

Os dados desta primeira versão ficam armazenados no navegador e dispositivo utilizados. Exporte backups regularmente. Evite limpar os dados do navegador sem salvar uma cópia.

Os módulos administrativos (alunos, horários, notas, financeiro e frequência) continuam armazenando os dados apenas neste navegador; eles não ficam sincronizados com o Supabase nem protegidos por login. Somente o Banco de Questões usa autenticação e biblioteca em nuvem nesta atualização. Evite cadastrar dados pessoais de crianças nas áreas não protegidas e mantenha backups locais.
